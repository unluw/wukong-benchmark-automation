# Black Myth: Wukong Benchmark — отчёт о тестировании

## 1. Характеристики тестового компьютера

| Компонент | Характеристика |
|---|---|
| Операционная система | Windows 10 (64-bit) |
| Процессор | Intel Core i5-12500H |
| Видеокарта | NVIDIA GeForce RTX 3060 Laptop GPU |
| Видеопамять | 6 ГБ |
| Оперативная память | 16 ГБ |
| Разрешение экрана | 1920 × 1080 |

## 2. Результаты тестирования

Для оценки производительности использовался Black Myth: Wukong Benchmark Tool. Проведены два теста с различными настройками качества графики.

| Показатель | LOW | HIGH |
|---|---:|---:|
| Средний FPS | 84 | 53 |
| Максимальный FPS | 121 | 74 |
| Минимальный FPS | 34 | 39 |
| 5-й перцентиль FPS | 38 | 44 |

## 3. Настройки графики

**LOW:** низкие настройки качества графики.

**HIGH:** высокие настройки качества графики.

Файлы с сохранёнными настройками каждого теста находятся в корне репозитория:

- `GameUserSettings.low.ini`
- `GameUserSettings.high.ini`

## 5. Сравнение результатов

Средний FPS при низких настройках составил **84 кадра/с**, при высоких — **53 кадра/с**.

Разница среднего FPS составляет **31 кадр/с**. Таким образом, при использовании низких настроек средняя частота кадров была примерно на 58,5% выше.

При этом минимальный FPS и 5-й перцентиль в HIGH-тесте оказались выше, чем в LOW-тесте. Такие показатели могут зависеть от условий отдельных прогонов, поэтому для оценки стабильности желательно повторить тестирование несколько раз.

## 6. Ограничения

- Результаты получены на одном тестовом компьютере.
- Для каждого пресета приведён один сохранённый результат.
- Отдельное измерение загрузки процессора и видеокарты не проводилось.
- Автоматическое распознавание FPS может требовать ручной проверки.

## 7. Вывод

При переходе с высоких на низкие настройки графики средняя частота кадров увеличилась с 53 до 84 FPS.

Низкие настройки обеспечили более высокую среднюю производительность в проведённых тестах. Для более точного сравнения стабильности FPS
