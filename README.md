# Автоматизация Black Myth: Wukong Benchmark Tool

Консольное приложение на **C# (.NET 10)** для автоматизации тестирования производительности компьютера с помощью Black Myth: Wukong Benchmark Tool.

## Описание проекта

Программа автоматизирует запуск бенчмарка с двумя наборами графических настроек, взаимодействие с интерфейсом игры, сохранение результатов и формирование итогового отчёта.

Реализованы два сценария:

- **LOW** — тестирование с низкими настройками графики.
- **HIGH** — тестирование с высокими настройками графики.

Основной режим позволяет последовательно выполнить оба сценария одной командой.

## Возможности программы

- Автоматический запуск Black Myth: Wukong Benchmark Tool через Steam.
- Применение заранее подготовленных графических пресетов LOW и HIGH.
- Взаимодействие с интерфейсом игры с помощью WinAPI.
- Последовательное выполнение двух тестов с закрытием игры между запусками.
- Автоматическое создание скриншотов результатов.
- Распознавание среднего, максимального, минимального FPS и 5-го перцентиля с помощью Windows OCR.
- Дополнительная обработка изображения для распознавания крупных стилизованных цифр FPS.
- Проверка полноты распознанных результатов.
- Формирование Markdown-отчёта с показателями FPS, настройками графики и характеристиками тестового компьютера.

## Требования для запуска

- Windows 10 или Windows 11.
- Установленный .NET 10 SDK.
- Steam и установленный Black Myth: Wukong Benchmark Tool.
- Поддержка русского языка в Windows OCR.
- Разрешение экрана 1920 × 1080 для воспроизведения протестированного сценария.

**Важно:** путь к установленному бенчмарку задан в `Program.cs`. При использовании на другом компьютере его необходимо изменить.

## Инструкция по запуску

Откройте PowerShell в папке проекта.

### Сборка

```powershell
dotnet build
```

### Полный автоматический запуск

```powershell
dotnet run -- --all
```

Программа последовательно:

1. Применяет LOW-пресет.
2. Запускает бенчмарк через Steam.
3. Автоматически запускает тест производительности.
4. Ожидает завершения теста и сохраняет скриншот.
5. Распознаёт показатели FPS.
6. Закрывает бенчмарк.
7. Повторяет процесс с HIGH-пресетом.
8. Формирует итоговый отчёт `results/report.md`.

Если распознаны не все показатели FPS, выполнение останавливается с сообщением об ошибке.

### Дополнительные команды

Запуск только LOW:

```powershell
dotnet run -- --low
```

Запуск только HIGH:

```powershell
dotnet run -- --high
```

Распознавание сохранённого LOW-скриншота:

```powershell
dotnet run -- --read --low
```

Распознавание сохранённого HIGH-скриншота:

```powershell
dotnet run -- --read --high
```

Повторное формирование отчёта по сохранённым скриншотам без запуска игры:

```powershell
dotnet run -- --report
```

## Результаты тестирования

| Показатель | LOW | HIGH |
|---|---:|---:|
| Средний FPS | **86** | **52** |
| Максимальный FPS | 116 | 72 |
| Минимальный FPS | 64 | 38 |
| 5-й перцентиль FPS | 77 | 43 |

При низких настройках графики средний FPS составил 86, при высоких — 52.

Снижение среднего FPS при переходе к высоким настройкам составило примерно 39,5%.

LOW и HIGH обозначают наборы графических настроек, а не подтверждённые CPU- и GPU-ограничения. Загрузка процессора и видеокарты отдельно не измерялась.

## Структура проекта

```text
WukongBenchmark/
├── Program.cs
├── WukongBenchmark.csproj
├── GameUserSettings.low.ini
├── GameUserSettings.high.ini
├── README.md
└── results/
    ├── cpu-low.png
    ├── gpu-high.png
    └── report.md
```

**Основные файлы:**

- `Program.cs` — автоматизация запуска, переключение настроек, взаимодействие с интерфейсом, создание скриншотов, распознавание FPS и формирование отчёта.
- `GameUserSettings.low.ini` — пресет низких настроек.
- `GameUserSettings.high.ini` — пресет высоких настроек.
- `results/cpu-low.png` — скриншот LOW-теста.
- `results/gpu-high.png` — скриншот HIGH-теста.
- `results/report.md` — итоговый отчёт.
- `WukongBenchmark.csproj` — конфигурация проекта .NET.

- Проверка автоматических нажатий в интерфейсе игры.

Полный последовательный запуск после последних изменений OCR отдельно не проверялся. При этом отдельные этапы сценария были проверены в ходе разработки.

## Ограничения и возможные улучшения

- Координаты нажатий рассчитаны на интерфейс игры с базовым разрешением 1920 × 1080. При другом масштабе или изменении интерфейса может потребоваться корректировка.
- Завершение теста определяется по фиксированному времени ожидания (4 минуты), а не по состоянию интерфейса.
- Windows OCR может ошибаться при распознавании стилизованных цифр. Для среднего FPS реализована дополнительная обработка изображения.
- Характеристики тестового компьютера в отчёте заданы вручную.
- Путь установки игры и Steam App ID рассчитаны на используемую конфигурацию.
- Для повышения надёжности можно добавить определение завершения теста по состоянию экрана, динамическое получение характеристик компьютера и дополнительные проверки распознанных значений.
